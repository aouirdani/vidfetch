# Maquette VidFetch v2 (référence visuelle)

Trois écrans exportés du canevas de design :
- Main.dc.html : accueil ordinateur (page fluide, pile 3D, étapes, outils, pied de page)
- Mobile-Home.dc.html : accueil mobile 390x844
- Mobile-Result.dc.html : choix du format mobile 390x844

Ces fichiers utilisent un format de maquette (balises <x-dc>, <helmet>, {{variables}}, <sc-for>, <sc-if>).
Ils servent de RÉFÉRENCE : couleurs, typographie, espacements, structure, CSS 3D et animations.
Ne pas les copier tels quels dans l'application : réimplémenter dans les composants Next.js existants.
